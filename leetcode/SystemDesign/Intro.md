### Product Design
Its basically system design. It's a type of interview where they ask to design a backend for a product

_Example Questions:_

- Design a ride-sharing service like Uber
    
- Design a chat application like Slack
    
- Design a social network like Facebook

### Infrastructure Design

Less common. Asked to design a system that supports a particular infra.
ex:
_Example Questions:_

- Design a rate limiter
    
- Design a message broker
    
- Design a key-value store
### Object Oriented Design

Also called low level design. Its for assembling the correct class structure adhering to the SOLID principles.
